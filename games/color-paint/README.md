# 🎨 认颜色 · 填涂小车

给两岁多小朋友玩的**认颜色 + 认字**游戏。

## 玩法

1. 从大厅点"认颜色涂小车"卡片 → **直接进入游戏**（无中间页）
2. 屏幕上出现一个颜色圆 + 一辆**灰色的小车**（车型每关随机）
3. 下方 3 个汉字按钮，点对应的颜色汉字
4. 选对 → 颜料飞溅 → 小车被涂上颜色 → 小车开走（向右出屏）
5. 下一关：**新车**从**左边开回来**到中央，颜色重新出题
6. 全部 10 关玩完 → 🎉 撒花完成页
7. 点"再玩一次" → **10 种颜色顺序再次洗乱**，重新开始

## 颜色（10 种）

红 / 橙 / 黄 / 绿 / 蓝 / 紫 / 粉 / 棕 / 黑 / 白

## 车型（7 种，每关随机）

- 轿车（Sedan）
- 出租车（Taxi，有顶灯）
- 巴士（Bus，多窗）
- 消防车（Fire，有云梯）
- 警车（Police，黑腰带 + 闪烁警灯）

- 挖掘机（Excavator，长机械臂 + 铲斗）

> 涂色覆盖车身主体 + 车舱（保持车型识别度）；警车的黑腰带、消防车的云梯、挖掘机的机械臂**不被涂色**，保持各自特色。

## 设计要点

- **大按钮**：汉字按钮 ≥ 110×90px，整屏占比 ≥ 25%
- **容错**：点错不扣分不惩罚
- **反馈强**：颜色圆 bounce / shake、按钮闪绿/闪红、颜料飞溅 12 粒、小车平滑开走 2.6s
- **循环动线**：中央 → 开走出右屏 → 下一关从左边开回来 → 中央
- **车身动画**：WAAPI `element.animate()` 控制 translate（绕开 CSS transition 冲突）
- **居中保证**：用 `translateX(calc(-50% + Npx))`，WAAPI 永远保留 `-50%` 居中基准
- **每次开局顺序随机**：10 色每次 `shuffle` 重新洗牌
- **跨设备**：touch + mouse 都支持

## 🔑 认字设计（v2.0 重点）

核心目标：**让小朋友真的记住「颜色 ↔ 字」的对应关系**，而不是靠排除法蒙。

### 点错后重新生成待选项

小朋友的典型作弊路径是：把 3 个选项挨个点一遍，总能碰到对的。
所以**每点错一次，整组待选项全部重新生成**：

- 2 个干扰项换成**本关还没出现过的**其他颜色（`usedDistractors` 记录已用过的）
- 3 个选项的**位置也重新打乱**，不能靠位置记忆
- 刚点错的那个词不再出现在新选项里

结果：小朋友顺着点一遍永远碰不到答案，必须先在脑子里把颜色和字对上。

### 不主动报答案

旧版答错会说「不对哦，是红色」——这等于直接把答案告诉小朋友了。
现在答错只说「再想想看～」+ 重念题目。

### 教学提示（连错 2 次才出）

连错 2 次后，在颜色圆下方用 **64px 大字**显示正确的颜色词 + 语音「看，是红色」。
这是**教认字**而不是泄题——他已经知道答案了，只是需要看到字和颜色对上。

### 💡 提示按钮

右上角灯泡按钮：点一下重念题目语音（不告诉答案）。
家长想让孩子重听一遍时用。

## 声音

TTS（中文语音）：
- 出题：「找红色」
- 答对：「对啦！红色」
- 答错：「再想想看～」（**不再报答案**）
- 连错 2 次：「看，是红色」+ 大字提示
